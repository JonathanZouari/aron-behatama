## באגים שנמצאו ותוקנו במהלך הבדיקות

1. **דיוק כספי ב-SQLite:** `numeric` קיבל affinity REAL והחזיר `1399.8399999…`. תוקן: `numeric → text` בדיאלקט SQLite.
2. **`soft_close`/`delivery`/`installation` קיבלו `"yes"` ו-`1`.** תוקן: `StrictBool`.
3. **הסוכן המדומה לא זיהה ״מילימטר״/״סנטימטר״** במילה מלאה. תוקן.
4. **חיבור SQLite משותף בין threads** גרם ל-404/500 בבקשות מקבילות בשרת הפיתוח. תוקן: נעילה סביב הגישה ל-DB.
5. **מרוץ ב-Dashboard/לקוחות:** תשובה ישנה ואיטית דרסה סינון חדש. תוקן: sequencing של בקשות.
6. **הודעה >2000 דרך script** עקפה `maxlength` (השרת דחה). תוקן: חיתוך בצד הלקוח.
